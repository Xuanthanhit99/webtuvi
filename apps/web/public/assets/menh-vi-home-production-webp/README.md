# Mệnh Vi Home production export

WebP assets exported from the approved text-free Home asset board.

- `backgrounds/`: full scene artwork.
- `feature-art/`: module artwork only.
- `hero-overlays/`: Tarot / Tử Vi / astrology / numerology visuals.
- `decor/`: supporting visual pieces.
- `mobile-visuals/`: mobile visual references.
- `reference/`: reference only; never crop in application code.

See `DATA_MAPPING.md` for fields that must come from application data.

Note: true transparency can only be preserved when present in the source image. This export does not fabricate alpha.
